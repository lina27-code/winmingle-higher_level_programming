# 0x05 - Python Exceptions

This project introduces error handling and exceptions in Python.

## Learning Objectives
- Difference between errors and exceptions
- Using try/except/else/finally
- Raising built-in exceptions
- Clean-up actions after exceptions

## Files
- `0-safe_print_list.py` – print x elements of a list
- `1-safe_print_integer.py` – print an integer safely
- `2-safe_print_list_integers.py` – print only integers from a list
- `3-safe_print_division.py` – divide two integers safely
- `4-list_division.py` – divide two lists element by element
- `5-raise_exception.py` – raise a TypeError
- `6-raise_exception_msg.py` – raise a NameError with message
- `100-safe_print_integer_err.py` – print integer, log errors to stderr
- `101-safe_function.py` – execute a function safely
- `102-magic_calculation.py` – replicate bytecode behaviour
- `103-python.c` – C functions for Python list/bytes/float info
