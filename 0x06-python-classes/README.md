# 0x06 - Python Classes and Objects

This project introduces Object-Oriented Programming in Python.

## Learning Objectives
- What is OOP
- Classes and objects
- Public, protected, and private attributes
- `self`, `__init__`, and methods
- Properties and getters/setters
- Data abstraction and encapsulation

## Files
- `0-square.py` - Empty Square class
- `1-square.py` - Square with private size attribute
- `2-square.py` - Square with validation
- `3-square.py` - Square with area method
- `4-square.py` - Square with property getter/setter
- `5-square.py` - Square with my_print method
- `6-square.py` - Square with position attribute
- `100-singly_linked_list.py` - Node and SinglyLinkedList classes
- `101-square.py` - Square with __str__ method
- `102-square.py` - Square with comparison operators
- `103-magic_class.py` - MagicClass from bytecode
